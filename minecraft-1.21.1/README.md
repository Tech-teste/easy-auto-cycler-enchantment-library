# Minecraft 1.21.1 — Addon 1.2.0 Beta

Favorites, reusable named book lists, mod-of-origin labels, selection review/clear, explicit payment limits, and the improved 1.1.0 interface. English and Brazilian Portuguese.

Build with Java 21. Download Easy Auto Cycler 3.1.0 for NeoForge / Minecraft 1.21.1 separately and put `easyautocycler-neoforge-1.21.1-3.1.0.jar` in libs/. Run `gradlew.bat build` on Windows or `chmod +x gradlew && ./gradlew build` on Linux. Output: build/libs/. Build includes integration, localization and saved-library checks. Original mod binaries are not redistributed here.

For use, install the addon on the client with compatible NeoForge, Easy Auto Cycler and Easy Villagers. Favorites and saved lists are stored in `config/easy-auto-cycler-library.json`. Loading a list changes the draft only: review and click Save and apply. See the repository README and NOTICE.md for full bilingual instructions and the personal-use / OpenAI Codex disclosure.
